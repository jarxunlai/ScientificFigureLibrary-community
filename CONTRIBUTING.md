# Contributing public templates

## Required order

Every release is submitted in two independently reviewed pull requests:

1. **Archive PR** to `jarxunlai/ScientificFigureLibrary-community-archives`.
2. A maintainer manually reviews and merges the Archive PR.
3. **Catalog PR** to this repository, pinned to that merge commit and the exact archive bytes.
4. A maintainer manually reviews and merges the Catalog PR.

Automation must not merge either PR.

## Rights and privacy

An archive must contain only specifically selected, redistributable assets. It must not contain:

- paper, publisher, WeChat, website, or book screenshots;
- cropped figures, renamed screenshots, watermarks, or source-reference images;
- paper PDFs or extracted panels;
- patient data or unpublished experimental data;
- a Local Library, locator, operations, receipts, quarantine, imports, or absolute machine paths;
- a private signing key or GitHub credential.

Code must use one role-wide license from `MIT`, `Apache-2.0`,
`BSD-3-Clause`, or `GPL-3.0`. Synthetic data, generated previews, and optional
documentation use one role-wide license from `CC-BY-4.0`, `CC0-1.0`, or
`CC-BY-SA-4.0`. A preview must be generated by the submitted code and permitted
data, with a render receipt.

Text provenance may cite a DOI or public URL and may state that a design was inspired by prior work. Such citations do not grant redistribution rights to third-party media.

## Immutable identity

Public identity is `providerId + templateId + semantic releaseVersion`. A merged version is immutable. Any byte change to code, data, preview, or metadata requires a new semantic version and content digest.

## Withdrawal and retired identities

A normal withdrawal is metadata-only and permits only `active -> withdrawn`.
It adds one immutable UTF-8 reason file and modifies only the standalone entry,
entries JSONL, Catalog envelope, and review. It does not modify or delete the
Archive, preview JSONL/manifest, thumbnail, policy, workflow, retired ledger,
or another release. The reason and `withdrawnAt` are immutable after merge.

Pre-v2 physically redacted identities are carried by the append-only retired
ledger. A retired identity is neither active nor withdrawn and cannot be
republished. No Catalog content PR is allowed to delete a release file.

## Allowed Catalog PR paths

A v2 Catalog addition may add only:

```text
catalog/entries/<templateId>/<releaseVersion>.json
catalog/thumbs/<templateId>/<releaseVersion>.png
reviews/<templateId>/<releaseVersion>.md
```

and may modify only:

```text
catalog/catalog.json
catalog/entries.jsonl
catalog/previews.jsonl
catalog/preview-manifest.json
```

Changes to `.github/**`, schemas, policies, or existing release paths require a separate maintainer-authored policy PR and are rejected from template submissions.
